# Funky Design Color System

Welcome to the definitive color reference for Funky Design. This system thrives on expression and vibrance, powered exclusively by OKLCH for predictable, uniform lightness and ultra-vibrant chroma.

## 3. Contrast-Checked Pairings

To maintain accessibility (aiming for WCAG AA compliance) and vibrant aesthetics, use the following pairings for text on accent backgrounds or accents on surface backgrounds.

| Accent Category | Background Surface | Recommended Text Color | Approx Contrast |
|-----------------|--------------------|------------------------|-----------------|
| **Coral 500** | Any Light/Dark | `--color-slate-950` (or Deep Brown) | 4.5:1+ |
| **Violet 500** | Sunlit / Overcast | `--color-slate-50` (or White) | 4.8:1+ |
| **Teal 500** | Midnight | `--color-slate-950` | 5.5:1+ |
| **Amber 500** | Midnight | `--color-slate-950` | 8.0:1+ |
| **Fuchsia 500** | Sunlit / Overcast | `--color-slate-50` (or White) | 4.5:1+ |
| **Lime 500** | Midnight | `--color-slate-950` | 10.0:1+ |
| **Slate 500** | Sunlit / Overcast | `--color-slate-50` | 4.5:1+ |

**General Rule of Thumb**: 
- For High-Luminance Accents (Amber, Lime, Teal): Use dark text (e.g. 900/950 values).
- For Mid-Luminance Accents (Violet, Fuchsia, Coral): Use light text (e.g. 50/100 values).

## 4. Gradient Recipes

These mesh gradient recipes use OKLCH for subtle background textures. They are designed for large hero sections or cards.

```css
/* 1. Coral -> Amber Warm Glow */
.bg-gradient-warm-glow {
  background: radial-gradient(circle at top left, var(--color-coral-400), transparent 70%),
              radial-gradient(circle at bottom right, var(--color-amber-300), transparent 70%);
}

/* 2. Violet -> Fuchsia Creative Energy */
.bg-gradient-creative {
  background: conic-gradient(from 180deg at 50% 50%, var(--color-violet-500) 0deg, var(--color-fuchsia-500) 180deg, var(--color-violet-500) 360deg);
}

/* 3. Teal -> Lime Fresh Growth */
.bg-gradient-fresh {
  background: radial-gradient(ellipse at center, var(--color-lime-300) 0%, transparent 60%),
              radial-gradient(ellipse at bottom left, var(--color-teal-400) 0%, transparent 80%);
}

/* 4. Amber -> Coral Sunset Warmth */
.bg-gradient-sunset {
  background: linear-gradient(135deg, var(--color-amber-400) 0%, var(--color-coral-500) 100%);
}

/* 5. Violet -> Teal Cool Creative */
.bg-gradient-cool {
  background: radial-gradient(circle at top right, var(--color-violet-400) 0%, transparent 60%),
              radial-gradient(circle at bottom left, var(--color-teal-300) 0%, transparent 60%);
}
```
